# Noto Sans для PDF

`NotoSans-Regular.ttf` и `NotoSans-Bold.ttf` — шрифты Noto Sans, лицензия SIL Open Font License 1.1 (`OFL.txt`).

Они нужны, чтобы титульный лист PDF (`lib/pdf/title-page.ts`) и демо-лекала корректно отображали кириллицу: стандартные шрифты PDF (Helvetica) её не поддерживают.

Источник: https://github.com/googlefonts/noto-fonts (OFL).
